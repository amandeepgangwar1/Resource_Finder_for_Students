AI resource tools

Explore the classification, summary, and question-answering tools available in Resource Finder.

Quick start

  1. Get free API key: https://huggingface.co/settings/tokens
  2. Add to .env: HF_API_KEY=hf_your_token
  3. Run: npm install && npm start
  4. Try the features below.

Semantic search

Find similar resources intelligently using TF-IDF and cosine similarity. Returns ranked results by relevance.

FREE INSTANT

Automatic classification

FREE 2-3 sec
